# PonyMail MCP Server

An MCP (Model Context Protocol) server that provides access to the [Apache PonyMail](https://ponymail.apache.org/) mailing list archive API.

It has moved to the official Apache Community Development git repo. Please see [https://github.com/apache/comdev/tree/main/mcp/ponymail-mcp](https://github.com/apache/comdev/tree/main/mcp/ponymail-mcp) instead.
